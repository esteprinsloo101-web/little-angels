# 10-Minute Daily Routine

**Goal:** Gentle consistency — not perfection.

| Minutes | Do this |
|---------|---------|
| 1–2 | Settle: water, bathroom, clear a small space |
| 3–7 | One practice game **or** one worksheet page |
| 8–10 | Read 3 word cards together **or** colour one shape |

## Stars chart

Use `worksheets/09_stars_chart.html` — one star sticker / colour-in per day you practice. Aim for kindness, not a streak guilt trip.

## Weekly mix (example)

- Mon: Letters  
- Tue: Numbers  
- Wed: Shapes  
- Thu: Word cards  
- Fri: Counting game / free choice  
- Weekend: Rest or outdoor shape hunt  

Parent/guardian supervised. Enrichment only — not a school timetable.
